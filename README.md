# «Спорттық клуб / Каратэ секциясы» веб-қосымшасы

## 1. Жобаның сипаттамасы мен мақсаты
Спорт секцияларына (каратэ) онлайн жазылуды және жаттығу кестесін басқаруды автоматтандыру үшін PHP және MySQL көмегімен веб-қосымша әзірлеу. 
**Мақсаты:** Пайдаланушыларды тіркеу, секцияларды таңдау және жазбаларды есепке алу процесін автоматтандыру.

## 2. Негізгі беттер
1. **Басты бет (`index.php`)** — клуб, каратэ секциялары және жаттықтырушылар туралы ақпарат.
2. **Авторизация және тіркелу беті (`login.php` / `register.php`)** — жүйеге кіру және аккаунт құру.
3. **Жеке кабинет (`dashboard.php`)** — таңдалған секцияларды қарау және жаңа сабақтарға жазылу.

## 3. Дерекқор құрылымы (3 кесте)
1. `users` — пайдаланушылар (id, аты, email, құпия сөз, рөлі, тіркелген уақыты)
2. `sections` — спорт секциялары (id, атауы, сипаттамасы, жаттықтырушы аты, бағасы)
3. `enrollments` — сабаққа жазылулар (id, қолданушы_id, секция_id, жазылған күні, күйі)

## 4. Қолданылатын технологиялар
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (PDO, Sessions)
* **Дерекқор:** MySQL (phpMyAdmin)
* **Орта:** XAMPP, VS Code
